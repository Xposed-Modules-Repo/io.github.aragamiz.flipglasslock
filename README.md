# FlipGlassLock

让 **Xiaomi MIX Flip 2 (HyperOS 3 / HyperOS 4)** 外屏锁屏与 AOD（息屏显示）完全同步内屏经典时钟样式——原生还原材质玻璃、镂空轮廓、字重调节以及全部 5 款官方字体（含方体 24 / Haus 25）。

- **源码仓库**：[Aragamiz/flipglasslock](https://github.com/Aragamiz/flipglasslock)
- **LSPosed 作用域**：仅需勾选 **系统界面 (`com.android.systemui`)**
- **支持系统**：Xiaomi MIX Flip 2 / HyperOS 3 & HyperOS 4
- **Release Tag 格式**：`68-1.0.68`（`[versionCode]-[versionName]`）

## 功能特性

- 锁屏时钟 1:1 同步内屏 `MiuiClockView` (`TimeView`) 样式与全部 5 款官方字体
- 完整支持材质玻璃、镂空轮廓与字重调节
- AOD 息屏平滑淡出与方体/Haus Path 轮廓补齐，消除唤醒过渡帧抽搐
- 内置设置页：支持日志导出与 `WRITE_SECURE_SETTINGS` 权限一键授权引导
